# E-Commerce Sales & Customer Analysis Using Python

## Project Overview

This project performs exploratory data analysis (EDA) on an e-commerce sales dataset containing 2,000 transactions. The analysis focuses on sales, profit, products, customers, customer segments, regions, and monthly sales trends.

The goal is to identify useful business patterns and present them through data analysis and visualization.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset

The dataset contains 2,000 e-commerce transactions with information about:

* Order details
* Customer names and segments
* Countries and regions
* Product categories and products
* Quantity and unit price
* Discounts
* Sales and profit
* Shipping cost
* Payment methods

## Analysis Performed

The project includes:

* Data cleaning and preprocessing
* Missing-value and duplicate checking
* Descriptive statistics
* Sales and profit analysis
* Product category analysis
* Regional analysis
* Monthly sales trend analysis
* Top product analysis
* Top customer analysis
* Customer segment analysis
* Correlation analysis
* Data visualization using charts

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or Jupyter Notebook.
3. Make sure Python is installed.
4. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

5. Open `ecommerce_analysis.ipynb`.
6. Run the notebook cells from top to bottom.

## Conclusion

The analysis provides an overview of e-commerce sales and profitability using Python-based exploratory data analysis. The visualizations help identify important patterns across products, customers, regions, customer segments, and time.
